  • Dominio:

    En HTML, el término "dominio" se refiere al nombre de dominio de un sitio web, no a un elemento HTML específico. Un dominio es la dirección que un usuario escribe en su navegador para acceder a un sitio web, como por ejemplo, "www.google.com". En el contexto de HTML, se usa para identificar la página web que se está navegando o para enlazar a otras páginas o recursos en la web.

  • Sub dominio:

    Un subdominio es una extensión de tu dominio principal que te permite crear secciones separadas y organizadas en tu sitio web.

  • URL:

    Una URL, o Localizador de Recursos Uniforme (Uniform Resource Locator), es la dirección web que identifica la ubicación de un recurso específico en la World Wide Web

  • DNS:

    Que significa "Domain Name System" o "Sistema de Nombres de Dominio", es el directorio telefónico de Internet.

  • Hosting:

    El "hosting" (o alojamiento web) es un servicio que permite almacenar y servir contenido web, como sitios web y correos electrónicos, en un servidor accesible a través de internet.

  • FTP:

    FTP, o File Transfer Protocol, es un protocolo de red estándar utilizado para transferir archivos entre un cliente y un servidor en una red TCP/IP.

  • HTTP:

    HTTP (Hypertext Transfer Protocol) es el protocolo de comunicación que permite la transferencia de información en la World Wide Web

  • HTTPS:

    HTTPS asegura que la información intercambiada entre el usuario y el sitio web no sea interceptada ni alterada por terceros, especialmente importante al transmitir datos sensibles como contraseñas, números de tarjetas de crédito o información personal.

  • W3C:

    El W3C, o World Wide Web Consortium, es una organización internacional que desarrolla estándares y directrices para la World Wide Web.

  • UTF-8:

    UTF-8 es un estándar de codificación de caracteres que utiliza 8 bits para representar caracteres Unicode.

  • HTMLS y su estructura:

    HTML (HyperText Markup Language) es el lenguaje principal para crear páginas web. Define la estructura y el contenido de una página web utilizando etiquetas que indican qué elementos se deben mostrar y dónde. La estructura básica de un documento HTML comprende una cabecera (< head>) con información sobre la página y un cuerpo (< body>) que contiene el contenido visible.
